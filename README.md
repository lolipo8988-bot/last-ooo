# Last Out of Office: The AI That Went Barista

Entry for the make.fun competition [Last Out of Office: The AI That Went Barista](https://make.fun/c/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

`main.py` writes one deterministic out-of-office auto-reply (a single
line, at most 280 characters) to `/output/entry.txt`: an AI agent that
quit to work in a cafe, whose old habit of hallucinating answers has
become mishearing names and writing them confidently on cups, while its
replacement is still loading.

Run it with:

```sh
python3 main.py
```
